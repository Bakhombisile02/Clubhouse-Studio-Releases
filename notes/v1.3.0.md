# Clubhouse Studio 1.3.0

Clubhouse Studio 1.3.0 protected long-running broadcasts from transient network failures and accidental system navigation.

## Changes

- Made preflight approval a one-time gate for each broadcast session.
- Added bounded reconnect backoff after interrupted RTMP output.
- Protected Back and the universal back gesture with an end-stream confirmation.
- Kept an approved broadcast foregrounded when Home or Recents temporarily covered Studio.
- Asked the operator to keep streaming or end explicitly when Studio returned.
