# Clubhouse Studio 1.3.6 Optic

Build 12. This is a separate Optic download. Existing releases remain available.

## Changes

- Upgrade RootEncoder from 2.6.7 to 2.8.1, including its camera, sender, buffer reuse, timestamp, and lifecycle improvements.
- Use byte queue and throughput statistics in adaptive bitrate control while retaining automatic reconnection, cooldown, gradual recovery, and existing bitrate limits.
- Add optional 11x and 12x zoom shortcuts. Select up to ten fullscreen shortcuts in settings. Defaults remain 0.6, 1, 2, 3, 5, and 10x.
- Preserve the fixed zoom row layouts. Normal view keeps the six optical shortcuts, and fullscreen shows this phone's selected shortcuts. Unsupported ratios are disabled according to the camera's reported range.
- Enable optical image stabilisation by default where supported, with an Off switch in settings. Android's recording template can provide automatic OIS. Electronic stabilisation is deferred.
- Add an orange camera level that fades when level, with no background or angle-number labels. It stays outside the recorded scoreboard.
- Retain two 20-minute Rugby League 13s halves, inline team-name suggestions, the colour wheel, and the released Winter Tournament Week fixes.
- Keep PYC Field 1, PYC Field 2, and PYC Field 3 configured under PASIFIKA YOUTH CUP - PYC. Existing destination edits, deletions, and custom destinations remain preserved.

## Validation

The candidate passed 172 unit tests and physical Galaxy S25 checks for zoom, settings, OIS, fullscreen controls, team suggestions, colours, local recording, microphone controls, and holding-page transitions. Prior authorized Field 1 tests exercised queue pressure, automatic reconnection, and simultaneous 1080p30 recording. Final publication checks verify the signed APK, private AAB, build number, checksum, and all three approved PYC entries.

S26 Ultra and Oppo have not been physically tested. This release does not claim native-camera colour equivalence or measured panning stabilisation. OIS and available zoom values depend on the phone. The S25 reports a 0.6 to 10x range, so 11x and 12x disable there.

## Install

Update between broadcasts. Download `CLUBHOUSE-v1.3.6-optic.apk` and verify it against `SHA256SUMS.txt`. Install it over an existing Clubhouse Studio app signed with the same production key to retain settings. Only one production Clubhouse Studio app is installed.

The operator explicitly approved public distribution with the three configured PYC fields. Build inputs, signing material, and Android App Bundles remain private. Uninstalling the existing app removes its saved settings and destinations. Existing public releases and tags are unchanged.
