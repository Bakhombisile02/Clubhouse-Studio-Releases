# Clubhouse Studio 1.2.0

Clubhouse Studio 1.2.0 made the final broadcast checks useful on a phone, repaired holding-screen media, and tightened the Live Studio scoreboard layout.

## Changes

- Distinguished local capture from RTMP and checked the relevant device, network, URL, and handshake state.
- Added a mobile pre-stream review for the selected sport, teams and colours, platform, sponsors, and holding page.
- Repaired holding-screen selection and persistence.
- Kept score, game segment, and timer metadata aligned for long participant names.
- Kept fullscreen exit controls clear and removed duplicate fullscreen controls.
