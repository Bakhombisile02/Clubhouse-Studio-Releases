# Winter Tournament Week v1.3.4

Use this build for Winter Tournament Week 2026.

## Tournament setup

- Keeps Winter Tournament Week pinned and visually distinct from the standard sport library.
- Organises tournament presets by sport and competition variant.
- Uses short labels such as `1st quarter`, `2nd half`, `3rd period`, and `9th end of 9`.
- Prevents the tournament-selection crashes covered by the physical-device regression suite.

## Broadcast graphics and controls

- Adds compact broadcast layouts for team sports, wrestling, and Indoor Bowls.
- Keeps scoreboards in the top-left safe area and constrains long names.
- Keeps the game state and clock aligned with the score.
- Uses a smooth variable-speed camera zoom, with the full 0.6x-to-10x move taking about five seconds.

## Network quality and reliability

- Adds upload and download throughput, latency, jitter, packet loss, server details, location, and test history.
- Explains Auto, HQ, and LQ in operator-friendly language.
- Improves Auto with congestion-aware bitrate adaptation, recovery steps, and thermal limits.
- Lets operators grant missing camera, microphone, and notification permissions from Console Settings.

## Verification

- 122 local unit tests passed.
- Android lint completed with no issues for debug and release variants.
- Eight instrumentation tests passed on a physical Samsung Galaxy S25 running Android 16.
- The device suite covered every distinct Winter Tournament Week format, score correction, clock and segment actions, extra ends, long-name layouts, fullscreen controls, local recording, and repeated sport selection.

Long-duration RTMP interruption testing remains scheduled for a field QA session. Tournament destinations were not contacted during this release validation.

## Install

Download `CLUBHOUSE-v1.3.4.apk` and `SHA256SUMS.txt` from this release. Verify the checksum before installation. Android accepts an in-place update only when the installed app uses the same Clubhouse signing key.
