# Clubhouse Studio 1.3.1

Clubhouse Studio 1.3.1 improved broadcast recovery, diagnostics, memory use, and thermal handling.

## Changes

- Restored camera preview and broadcast graphics after returning from Home or Recents.
- Added private crash and broadcast diagnostics.
- Added interrupted-broadcast recovery with score, game segment, and paused-clock restoration.
- Bounded overlay image decoding and serialized image work.
- Added thermal safeguards and reduced sponsor work under severe heat.
