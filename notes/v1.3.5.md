# Clubhouse Studio v1.3.5

Build 9. This is the post-tournament update for authorized Clubhouse operators.

## Before updating

**This update clears saved RTMP destinations once.** Copy any destination you still need to your approved secure records before installing. Obtain current access details from your event lead.

On the first launch after upgrading, Persistent Events is empty. The update also removes last-used RTMP credentials, recent broadcast shortcuts that contain credentials, and recovery references to removed shortcuts. Local recording setups and unrelated settings remain. Destinations that you add after the reset stay saved on subsequent launches.

Update between broadcasts. Do not uninstall the existing app. Install the signed APK as an update.

## Changes

- Removes the built-in tournament destination catalogue from the app and release builds. Fresh installations contain no preloaded event links or stream keys.
- Removes the Winter Tournament Week folder from Choose Your Sport. Regular sports, custom sports, and saved sport configurations remain available.
- Returns restored pre-update network screens to destination setup so Android cannot reintroduce a retired link from saved screen state.
- Includes the reviewed repository cleanup from PR #63, including removal of obsolete assets and the unavailable Remote Scoring entry.
- Retains the existing Live Studio controls, scoreboards, camera behavior, recording, and stream recovery. This release does not implement remote scoring or change dependencies.

## Validation limits

No phone was available for this release. The owner requested publication using non-device checks. Physical-device installation, camera operation, local recording, fullscreen layout, and interruption recovery were not retested. Previous Galaxy S25 results apply to the earlier baseline, not to this release candidate.

No emulator or external RTMP destination is used during release validation. Build, automated-test, signature, and checksum evidence is recorded in the private release issue.

Local checks passed: 142 JVM tests, six artifact-guard tests, debug and release lint with zero errors, debug and release APK builds, AAB packaging, and instrumentation-source compilation. Instrumentation tests were compiled, not run. Lint retains 183 warnings in each variant.

## Download and access

Download `CLUBHOUSE-v1.3.5.apk` and compare its SHA-256 with `SHA256SUMS.txt`. Android may request permission to install from your browser. Use only the official Clubhouse release channel and approved event credentials.

The APK is signed for direct upgrades of prior APKs with the same signer. A Play-installed app may use a different signing certificate. Google Play Protect makes its own trust decisions; this release does not promise to suppress its warnings.

Remote Scoring remains unavailable. The Android App Bundle stays private for Play Console submission.
