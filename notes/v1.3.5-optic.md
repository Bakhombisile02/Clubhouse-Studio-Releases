# Clubhouse Studio 1.3.5 Optic

Build 11. This is a separate public Optic download. Existing 1.3.5 and 1.3.6 releases remain unchanged. Optic uses the existing Clubhouse Studio production package and signing key.

## Changes

- Configure this phone's zoom buttons in Live Stream Settings. Tap to select 0.6×, 1.5×, and every whole value from 1× to 10×. Defaults are 0.6, 1, 2, 3, 5, and 10×. Selected buttons are orange with a checkmark; unselected buttons are grey.
- Keep the existing 1.3.5 single-row zoom layout and button sizes. Normal view uses the six fixed optical shortcuts; fullscreen uses the selected shortcuts. Leaving fullscreen retains higher zoom ratios.
- Keep smooth transitions. Ratios outside the active camera's range are disabled. Android's camera system chooses the available lenses. A zoom label does not guarantee an optical lens at that ratio.
- Add Cook Islands, Niue, Samoa, Tonga, and Aotearoa Maori to team-name suggestions in setup and live settings. Live settings also includes the existing full colour wheel with brightness and hex/RGB entry.
- Rugby League (13s) defaults to two 20-minute countdown halves.
- Retain the released Winter Tournament Week scoreboard, smooth zoom, fullscreen, quality, and interruption-recovery fixes from the 1.3.5 baseline. UI Pass 3 prototype work remains separate.
- Preload PYC Field 1, PYC Field 2, and PYC Field 3 under PASIFIKA YOUTH CUP - PYC. Optic adds them once. Later edits and deletions persist, and existing destinations survive.

## Validation

The Galaxy S25 passed 11 Optic and regression tests, plus the Base smooth-zoom test. Base ↔ Optic test updates preserved all 13 preference files. Each edition passed 157 JVM tests, debug/release lint, and release APK/AAB builds. The owner chose to handle installation and edition compatibility manually for this release. Signed APK metadata, signer, and checksums are verified before publication. Validation evidence is tracked in private release issue #235. S25 results do not establish S26 Ultra physical-lens behavior. No external RTMP destination is contacted during local-recording checks.

## Distribution

The Optic APK contains the supplied PYC access details. The owner explicitly approved a public GitHub Optic APK with all three configured PYC fields. Build inputs and Android App Bundles remain private. Existing release assets and tags must remain available and unchanged.

## Install

The operator installs 1.3.5 Optic manually and keeps only one Clubhouse Studio app installed. If you uninstall an existing app first, its saved settings and destinations are removed. Optic includes the three configured PYC fields on first use.

Update between broadcasts. Existing 1.3.5 and 1.3.6 releases are unchanged.
